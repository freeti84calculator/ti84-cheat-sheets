# TI-84 Cheat Sheets

Quick keystroke cheat sheets for the TI-84 Plus CE — the exact keys to press, in order.

## Sheets
- **Statistics:** mean, standard deviation (1-Var Stats), z-scores, normalcdf
- **Graphing:** window settings, ZStandard / ZDecimal / ZSquare, histograms
- **Errors:** what ERR:SYNTAX, ERR:DIM MISMATCH and ERR:WINDOW RANGE mean, and the fix
